## 어떤 문제를 해결하나

Drive 홈은 시간이 지나면 추천 파일 목록이 곧 잡동사니 목록이 됩니다. 보고서, 서류, 아이 학습 자료, 스크린샷, 영상 테스트 파일이 한 줄에 섞여 있습니다.
정리하려면 파일마다 "이건 뭐였지" 를 떠올려야 하고, 그게 귀찮아서 안 합니다.

Ask Gemini 패널에 Drive 홈을 보여 주고 "용도별로 분류해 표로" 라고 하면, **분류표와 폴더 구조 제안**까지는 1분입니다. 그다음 **실제 이동은 못 합니다** — 이 사례는 그 경계를 그대로 보여 줍니다.

## 사전 준비

- Chrome + Ask Gemini 패널, Gemini 에 Google Workspace 앱(Drive) 연결
- Drive 홈(`drive.google.com/drive/home`)을 연 탭

## 단계별 사용법

{{< step title="Drive 홈을 열고 패널의 Sharing 줄을 확인한다" image="01-home.png" caption="Sharing '홈 - Google Drive'. 추천 파일 목록이 보이는 상태에서 시작합니다." >}}
Drive 홈에서 `✦ Ask Gemini` 를 엽니다. 입력창 위 `Sharing "홈 - Google Drive"` 가 뜨면 패널이 이 탭을 보고 있는 겁니다.

이 시점에 화면에는 추천 파일 8개 정도가 보입니다. 화면 밖에 더 있는 건 "더보기" 를 눌러야 나옵니다 — 이게 뒤에서 확인할 포인트입니다.
{{< /step >}}

{{< step title="열 구성을 정해서 분류를 요청한다" image="02-table.png" caption="'Workspace ▾' 라벨이 붙은 분류표. 파일명 / 분류 / 제안 폴더명 / 이유. 화면에 없던 파일도 표에 들어 있습니다." >}}
{{< prompt title="입력 프롬프트" >}}
지금 보이는 Drive 파일들을 용도별로 분류해서 표로 정리해줘. 열은 파일명 / 분류 / 제안 폴더명 / 이유. 마지막에 새로 만들 폴더 목록을 정리해줘.
{{< /prompt >}}

표가 돌아왔습니다. 두 가지를 봅니다.

- **`Workspace ▾` 라벨** — 화면 텍스트가 아니라 Drive 앱으로 파일 목록을 읽었다는 표시. 그래서 "지금 보이는" 이라고 했는데도 **화면 밖 파일**(`report.md` 등)까지 표에 들어갔습니다. 화면 목록만 다루게 하려면 파일명을 직접 나열해야 합니다
- **이유 열** — "2026년 인프라 자동화 및 AI 대응에 대한 전문 조사 분석 리포트" 처럼 파일 **내용**을 근거로 분류했습니다. 파일명만 보고 짐작한 게 아닙니다. PNG 두 개는 파일명의 `시뮬레이션`, `전략비교` 로 분류했습니다

분류 결과(일반화): 리포트/기술 문서 · 교육/학습 자료 · 행정/개인 서류 · 미디어 테스트 · 전략 시뮬레이션 이미지 · Gem 보조 도구.
{{< /step >}}

{{< step title="폴더 제안 목록을 받는다" image="03-folders.png" caption="새로 만들 폴더 7개. 기존 폴더 하위로 넣을 것은 '(기존 X 폴더 하위)' 로 구분했습니다." >}}
표 아래에 폴더 목록이 정리됩니다.

- `인프라_AI_리포트`, `개인_서류`, `미디어_테스트`, `전략_시뮬레이션`, `Gem_보조툴` 등 7개
- 하나는 `(기존 ○○ 폴더 하위)` 로, 이미 있는 폴더 밑에 만들라고 제안 — Drive 의 기존 폴더 구조를 읽었다는 뜻입니다

폴더명 규칙(한글_밑줄)은 통일돼 있어서 그대로 써도 됩니다. 규칙을 바꾸고 싶으면 프롬프트에 `폴더명은 영문 소문자-하이픈` 처럼 적습니다.
{{< /step >}}

{{< step title="옮겨 달라고 하면 '지원되지 않는다'고 답한다" image="04-cannot-move.png" caption="'Google Drive 인터페이스를 직접 조작하거나 폴더를 생성하고 파일 위치를 변경하는 기능은 지원되지 않습니다.' 대신 수동 절차 3단계." >}}
{{< prompt title="입력 프롬프트" >}}
제안한 폴더를 만들고 파일들을 그 폴더로 옮겨줘
{{< /prompt >}}

> 현재 사용 중인 Google Drive 인터페이스를 직접 조작하거나 폴더를 생성하고 파일 위치를 변경해 드리는 기능은 지원되지 않습니다.

대신 ① `+ 신규 → 새 폴더`, ② 드래그 앤 드롭 또는 `⋮ → 이동`, ③ 폴더 열어 확인 — 3단계 수동 절차를 줍니다.
Ask Gemini 의 Drive 연동은 **읽기 전용**입니다. 캘린더에 일정을 만드는 것과 달리, Drive 는 쓰기 액션이 없습니다.
{{< /step >}}

## 결과

"뭐가 뭔지" 떠올리는 일이 사라졌습니다. 분류표 + 폴더 7개 제안까지 1분, 실제 이동은 파일 10개 기준 2~3분 손작업.
전에는 정리 자체를 안 했으니, 비교 대상은 "0분 → 4분" 이 아니라 "안 함 → 함" 입니다.

## 주의사항

- **"지금 보이는" 이 안 먹힙니다.** Workspace 앱이 붙으면 Drive 전체(최근·추천)를 읽습니다. 범위를 한정하려면 파일명을 나열하거나, 특정 폴더를 열어 두고 "이 폴더 안" 이라고 하세요 — 그래도 앱이 우선일 수 있으니 결과 표의 파일명을 확인합니다.
- **분류 근거는 파일 내용입니다.** 문서 파일은 본문을 읽고 분류하므로, 민감한 문서(계약서·개인 서류)도 읽힙니다. 회사 계정이면 관리자 정책을 확인하세요.
- **이동은 못 합니다.** 폴더 생성·이동·이름 변경은 Ask Gemini 범위 밖입니다. 자동화까지 원하면 Drive API 스크립트나 에이전트 브라우저([ego lite]({{< relref "/docs/usecases/automation/ego-lite-browser-agent-driving" >}}))로 넘어가야 하는데, 이 세션에서는 Drive 쓰기 작업이 Claude 안전장치에 막혔습니다. 막히는 게 맞습니다.
- 캡처에는 개인 파일명이 그대로 뜹니다. 공유 전 픽셀화하세요. 이 페이지도 그렇게 했습니다.

## 응용

- 다운로드 폴더를 Drive 에 올린 뒤 같은 프롬프트 → 정리 계획표
- `공유 문서함` 을 열어 두고 "누가 보낸 뭔지 표로" → 공유받은 파일 정리
- 분류표의 "이유" 열을 그대로 파일 설명(Drive 세부정보의 설명란)에 붙여 넣기
- 폴더 제안을 받은 뒤 사람이 옮기고, 한 달 뒤 같은 프롬프트로 "새로 들어온 파일만" 재분류
