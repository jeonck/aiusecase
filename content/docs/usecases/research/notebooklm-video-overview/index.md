## 어떤 문제를 해결하나

신입에게 "이 보고서 읽어 봐" 는 안 읽힙니다. 8분짜리 설명 영상은 봅니다.
NotebookLM 의 **동영상 개요**는 소스에서 나레이션 + 손그림 스타일 슬라이드 영상을 만듭니다. [오디오 오버뷰]({{< relref "/docs/usecases/research/notebooklm-audio-overview" >}})가 귀로 듣는 용도라면, 동영상은 위키에 박아 두고 보는 용도입니다.

같은 노트북에서 스튜디오 항목 하나를 더 누른 것이라, 이 보고서 하나로 데이터 표 · 마인드맵 · 슬라이드 · 오디오 · 동영상 다섯 가지가 나왔습니다.

## 사전 준비

- 소스가 올라간 NotebookLM 노트북
- **한도 여유가 가장 큰 항목입니다.** 이 사례에서 동영상을 만든 직후 "AI 사용량 한도에 거의 도달" 경고가 떴습니다
- 12분 정도 기다릴 여유. 생성만 맡기려면 ego lite ([활용법]({{< relref "/docs/usecases/automation/ego-lite-browser-agent-driving" >}}))

집중할 부분에는 소스에서 뽑은 **추천 주제 칩**(`AI 인프라 자동화 준비 격차`, `인프라 자동화의 핵심 성공 전략`, `2026년 자동화 기술 3대 핵심`)이 미리 떠 있습니다. 칩을 고르면 그 주제 중심으로, `맞춤 주제` 를 누르면 직접 씁니다.

팀 위키에 올릴 신입 플랫폼 엔지니어용 설명 영상. 구성: 1) AI 도입이 인프라 팀에 준 부담(수치), 2) AIMI 4단계와 우리 팀 진단 질문 3개, 3) 다음 분기 우선순위 3가지. IaC·바이브 코딩·플랫폼 엔지니어링 같은 용어는 처음 나올 때 한 줄로 풀어 설명. 화면에 숫자를 쓸 때는 대상 그룹(전체 응답자/Pioneer/Exposed)을 자막에 같이 표기.

슬라이드·오디오와 같은 3부 구성에 두 가지를 더했습니다. **용어 풀이**(신입 대상이니까)와 **자막 규칙**(숫자의 주어가 바뀌는 걸 앞 사례에서 봤으니까).

`지금 생성` 후 **712초**(11분 52초). 길이 8:00, 제목 `팀 온보딩: AI 가속 인프라` — "팀 위키 온보딩용" 이라고 적은 걸 제목이 받았습니다.

같은 노트북에서 오늘 데이터 표 → 마인드맵 → 슬라이드 → 오디오 → 동영상을 연달아 만들었더니 한도 경고가 떴습니다. 동영상이 가장 비쌉니다. 한도는 5시간마다 초기화되고, 넘으면 `나중에 생성` 으로 대기열에 넣을 수 있습니다.

```js
await page.waitForFunction(
  () => /동영상 개요.*준비되었습니다/.test(document.body.innerText),
  undefined, { timeout: 900000 });   // 15분까지 기다린다
```

## 결과

보고서 PDF → 8분 온보딩 영상. 사람이 한 일은 프롬프트 한 줄, 그리고 훑어보기 5분.
손그림 스타일의 일관된 비주얼, 목차·용어 풀이·진단 질문 구조는 그대로 위키에 올릴 만합니다. 자막 규칙 미반영과 한글 줄바꿈 두 가지는 알고 공유해야 합니다.

## 주의사항

- **동영상은 한도를 가장 많이 씁니다.** 하루에 한 노트북에서 여러 스튜디오 항목을 뽑을 계획이면 동영상을 마지막에 두거나, 한도 초기화 시각(경고 배너에 표시)을 보고 나눠서 만드세요.
- **12분은 기본입니다.** 자동화하면 기다리는 동안 다른 일을 할 수 있습니다. 사람이 직접 하면 `나중에 생성` 으로 넣고 잊는 편이 낫습니다.
- **영상 속 한글 줄바꿈은 손댈 수 없습니다.** 제목·인용문이 한 글자만 다음 줄로 떨어지는 일이 있습니다. 긴 제목은 집중할 부분에 짧은 제목 후보를 적어 주세요.
- **자막 규칙 같은 세부 지시는 반영이 약합니다.** 구성·청중·용어 풀이는 잘 따르지만, "자막에 X를 표기" 수준은 안 지켜질 수 있습니다. 숫자가 중요한 영상이면 데이터 표를 같이 공유하세요.
- **번역 용어를 확인하세요.** shadow AI 가 "AI 꼼수" 로 나왔습니다. 팀 용어와 다르면 집중할 부분에 "shadow AI 는 '섀도 AI' 로 표기" 처럼 지정합니다.
- 다운로드 버튼은 있지만 에이전트 세션에서는 파일이 떨어지지 않았습니다(슬라이드·오디오와 동일). 내보내기는 사람이 누릅니다.

## 응용

- **짧은 버전(9:16)** 으로 같은 내용 90초 → 슬랙 공지에 첨부
- 사내 규정 PDF → "신입이 첫 주에 알아야 할 것" 영상 → 온보딩 위키 첫 페이지
- 분기 보고서 3개 → "지난 분기 대비 달라진 것" 영상 → 전사 공유
- 영어 원문을 **영어** 영상으로 만들어 해외 팀에 그대로 전달
